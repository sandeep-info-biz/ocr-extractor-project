📦 WHAT'S IN THIS FOLDER?

This folder contains everything you need to run your Python OCR 
service on a different device/server. Just copy this entire 
folder to your server and run the setup script!

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🎯 SUPER QUICK START (3 Steps)

1️⃣  COPY TO SERVER
   
   Option A - Automated:
   ./deploy_to_remote.sh user@192.168.1.100
   
   Option B - Manual:
   tar -czf ocr-server.tar.gz remote_server/
   scp ocr-server.tar.gz user@192.168.1.100:/home/user/

2️⃣  ON SERVER, RUN SETUP
   
   ssh user@192.168.1.100
   cd remote_server  # or extract tar.gz first
   chmod +x *.sh
   ./setup.sh
   ./start_server.sh

3️⃣  UPDATE YOUR JAVA APP
   
   export PYTHON_SERVICE_BASE_URL=http://192.168.1.100:8000
   mvn spring-boot:run

⚙️  CONFIGURATION

Edit .env file to customize:
- PORT (default: 8000)
- HOST (default: 0.0.0.0 - accessible from network)
- CORS_ALLOW_ORIGINS
- SIMPLYPARSE_API_TOKEN
